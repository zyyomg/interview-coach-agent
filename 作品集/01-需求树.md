# 面试陪练 Agent · 需求树

> 用法：Xmind → 文件 → 导入 → Markdown，直接生成思维导图；也可以照着这个层级手画。
> 优先级：P0 = 没有它产品不成立；P1 = 影响体验但可延后；P2 = 锦上添花。
> 版本：v1.1（对应代码 2e5a8bc 之后的作品集接入）

## 1 面试对练

### 1.1 开局配置
- 岗位选择（P0）
  - 手写岗位名：写什么岗位就按什么岗位真实会问的出题
  - 通用岗位：唯一预设，写不出具体岗位时的兜底
  - 历史岗位：写过的存本地（8 条），下次一键填回
  - 预设与输入互斥，选完标题即时反馈
- 话题数（P0）
  - 6 / 8 / 10 / 12 四档，默认 8
  - 到达上限自动收尾
- 难度（P1）
  - 简单 / 标准 / 困难
  - 只改三件事：短句阈值、是否强制要数字、提问深度
  - 不改判定顺序
- 面试方式（P0）
  - 体验式：不带材料，岗位通用题
  - 正式：简历必须给，从项目切进去
  - 选正式没给简历 → 前后端各拦一次，不静默降级
- 简历导入（P0，仅正式）
  - 支持 .docx / .pdf / .txt / .md
  - 支持直接粘贴正文
  - PDF 只读文字层；扫描件 / 图片型读不出字 → 明确提示另存或粘贴
  - 原文不落盘，只记文件名与字数
- 作品集导入（P1，仅正式，可选）
  - 多份文件（最多 6 份），可单独删除、可同名替换
  - 只有作品集没有简历 → 仍然拦（正式场要的是"人"，不是产物）
  - 提示词按份分配 1600 字：每份保底 200 字，余额补给前面的文件
  - 至少 1 个话题从作品集出，问法是"为什么这么设计 / 这个数怎么算的"
  - 支持额外粘贴一段补充说明
  - 原文不落盘，只记份数、文件名、字数

### 1.2 多轮对话
- 一次只问一个问题（P0）
  - 单句上限 60 字，超长强制拆句
- 判定动作（P0）
  - 澄清：识别为空或实字数 < 4
  - 追问：偏短（< 22 字）或"有内容没细节"（无数字、无结果）
  - 换题：命中放弃词且整句就是在说不会，换更基础的同类问题
  - 推进：够具体，进入下一话题
  - 收尾：到达话题上限
- 动作上限（P0）
  - 每题最多追问 2 次、澄清 2 次、换题 2 次
  - 到上限强制推进，不得把候选人卡死在同一题
- 上下文（P1）
  - 最近 30 轮进模型上下文
  - 超出后丢弃最早轮次，不截断当前轮

### 1.3 语音
- 语音识别（P0）
  - 浏览器 Web Speech，边说边出字
  - 断线自动重连：4 / 7 / 12 / 20 / 30 秒退避
  - 引擎假活：心跳每 12 秒换新识别器
  - 手动重连：点一次麦克风立即重连
  - 识别不可用 → 降级为打字，播报不跟着关
- 语音播报（P0）
  - 按句切分，一句就念，不等全文
  - 播报中可被打断
- 打断（P0）
  - 打断即停：本轮作废，后续只出字幕不出声
  - 防误触发四条件：识别 ≥ 4 字、播报开始 500ms 后、距上次打断 ≥ 2s、非回声
- 冷场处理（P1）
  - 4.5 秒无输入判为说完，自动提交
  - 长时间不开口 → 先催一句，再换更基础的问法

### 1.4 异常与兜底
- 识别断连不结束本场（P0）
- 模型不可用 → 演示模式（P1）
- 服务未启动 → 页面明确提示"连不上本地服务"（P0）

## 2 复盘

### 2.1 总体评价
- 总分 0–100（P0）
- 一句话总评，20 字内（P0）
- 3 条优势，必须引用候选人原话（P0）
- 3 条改进，每条含问题 + 可执行改法（P0）

### 2.2 逐题复盘
- 题目简述（P1）
- 一句话点评（P0）
- 答题思路：先说什么、后说什么（P0）
- 该备哪些数：点名要报的数字或事实（P0）
- 参考答法：60–90 字，第一人称，必须带一个具体数字（P0）

### 2.3 输出
- 页面弹窗（P0）
- 下载 .md（P1）
- 归档到 runs/，往期可翻（P1）
- 模型返回不完整 → 明确说明"这次没有范本"，不假装有（P0）

## 3 数据与统计

### 3.1 本次指标
- 已答话题数 / 总话题数（P0）
- 追问、澄清、换题、打断次数（P0）
- 平均回答字数（P1）
- 首字延迟、首音延迟（P1）

### 3.2 成本
- 逐轮累加接口返回的 token 用量（P0）
- 分时段计价：工作日白天全价，其余半价（P1）
- 接口没给用量时退回估算并标注（P1）

### 3.3 往期
- 列出历史场次（P1）
- 可回看复盘与记录（P1）

## 4 不做（明确划出去）

- 不做真人面试的替代品，定位是高频低成本的练习工具
- 不做题库：岗位题由模型按岗位名生成，不人工维护题集
- 不做账号体系与云端存储：本地跑，数据留在自己机器上
- 不做视频面试模拟：语音已经够用，加摄像头不解决核心问题
- 不做简历优化建议：那是另一件事，混进来会让复盘失焦
- 不做作品集排版 / 设计评审：只拿它出题和追问，不评价做得好不好看
