# Figma 操作手册：把「面试陪练」搭成设计稿

> **这份文档是干什么的**：你现在只有一个能跑的网页产品和一个手机尺寸的 HTML 原型，简历上写「Figma」还站不住。这份手册带你用半天时间，在 Figma 里把这个产品重搭一遍，产出一个**能发给面试官的设计文件 + 可点击链接**。
>
> **产出物**：一个 Figma 文件，3 个画板（首页 / 对练中 / 复盘），一套组件库，一套颜色和文字样式，3 条能点通的跳转。
>
> **总耗时**：约 4 小时 15 分。时间不够看第 9 节，有 2 小时和 3 小时的砍法。

---

## 三条路线，先选一条

| | 路线 C：拖 SVG（先试这个） | 路线 A：插件导 HTML | 路线 B：手动搭 |
|---|---|---|---|
| 怎么做 | 把 `figma/svg/` 里三个 `.svg` 直接拖进画布 | 用 html.to.design 插件导 `三屏设计稿.html` | 从空文件照第 1–7 节一步步点 |
| 耗时 | 2 分钟，不联网、不装插件 | 约 40 分钟（含装插件 + 清理） | 约 4 小时 |
| 你得到 | 三屏矢量图层，文字是真文字 | 三屏图层，分组和命名更规整 | 结构完全由你定 |
| 代价 | 全是绝对定位，没有 Auto Layout | 第三方插件，免费额度有限 | 慢，但每一层你都清楚为什么在 |

**先说清一件事**：`html.to.design` 官方 FAQ 明确写了 flexbox 和 grid **不会**转成 Auto Layout，导入结果同样是一堆固定坐标的图层。所以路线 A 比路线 C 多花的 40 分钟，买不到「自动布局」，只买到更整齐的分组命名。两者产出的结构是同一类东西。

真正决定这算不算一张设计稿的，是后面两件：**抽组件**（第 4 节）和**连线**（第 6 节）——任何一条路线都省不掉，也正是面试官会问的。

下面的 **第 0 节是路线 C 和 A 的完整操作**，第 1–7 节是路线 B（也是 A/C 清理时的参考）。

---

## 0. 路线 C：拖 SVG 进 Figma（2 分钟）

`作品集/figma/svg/` 里三个文件，每个正好 1440×900，就是三屏本身：

| 文件 | 内容 | 文字层 | 色块/描边 |
|---|---|---|---|
| `01-首页.svg` | 开工前 | 66 | 121 |
| `02-对练中.svg` | 问到第 2 题，追问 | 69 | 132 |
| `03-复盘.svg` | 遮罩 + 760 宽弹层 | 95 | 149 |

1. 把三个 `.svg` 一起拖进 Figma 画布（或 `Ctrl+Shift+K` 置入）
2. 选中导入后的容器 → `Ctrl+Alt+G` 包成 Frame → `W 1440`、`H 900`，命名 `01 首页`（三屏都做一遍）
3. 全选 → 字体若是红叹号，换成 `Noto Sans SC`（或 `Microsoft YaHei`），标题 600、正文 400
4. 阴影丢了一部分（SVG 里没写 filter）：选中卡片和弹层，在右侧 `Effects` 加你建的 `shadow/卡片` 样式
5. 接着走第 4 节抽组件、第 6 节连线

**已知差别**（不影响观感，改稿时知道就行）：

- 文字是独立文本层、绝对定位，改文案要自己挪位置——和插件导入一样的代价
- 列表前的小圆点是 `::before` 伪元素，SVG 里没有；要的话画个 4×4 圆点
- 内联图标（麦克风 / 附件 / 时钟）是真矢量路径，可以改颜色
- 想重新生成：`python dev/html2svg.py`（需要 playwright，会导出再渲染回图自检；实测与原稿平均色差 1.4–3.8/255）

## 0. 路线 A：用插件把 HTML 导进 Figma（40 分钟）

### 0.1 先确认这个文件是什么

`作品集/figma/三屏设计稿.html` —— 我按你已经建好的那套颜色和文字样式，把三个 1440×900 的屏写成了成一份自包含 HTML：

- 尺寸、间距、圆角、字号全部对齐 `web/style.css`，不是另画一套
- 每屏是一个 `<section class="screen">`，正好 1440×900，没有溢出（渲染验证过）
- 用 flex 布局写的，不是绝对定位——这样转换时更容易保留成 Auto Layout
- 同目录下 `01-屏@2x.png` / `02-屏@2x.png` / `03-屏@2x.png` 是渲染出来的效果图，导之前先看一眼对不对

### 0.2 装插件

1. **别在 `Shift + I` 那个搜索框里搜**。那是 **Assets（资产）** 面板，右边带 `All libraries` 下拉，只搜组件和样式，搜插件永远返回 *No results*
2. 正确的入口有两个：
   - 左上角 **Figma 图标 → Plugins → Manage plugins…**，弹窗顶部的搜索框
   - 或 `Ctrl + /`（Actions）输入 `html to design`，选最后一条 **Browse plugins in Community**
3. 搜 **`html to design`**（空格，不要打成 `html.to.design`），作者是 **‹div›RIOTS**，蓝色图标
4. 点 **Run**，第一次会要你授权
5. 社区里打不开、或提示不可用，就直接走路线 C，别在这儿耗时间

> 也可以浏览器直接开 `figma.com/community/plugin/1159123024924461424`，点 **Open in Figma**。
> 免费版有导入额度（按它的政策，免费档每月次数有限），三屏够用。

### 0.3 导入

1. 插件面板里选 **Import from file**（有的版本叫 *Import from HTML*），不要选 *Import from URL*——URL 那条路是它服务器去抓，抓不到你本机
2. 上传 `作品集/figma/三屏设计稿.html`
3. 它解析完会列出可导入的节点，勾选 **三个 `.screen`**（编号 1、2、3），别的不要勾
4. 点 **Import**，等 10–30 秒

### 0.4 导入后必做的四件事（15 分钟）

**① 每屏包进一个 1440×900 的 Frame**
导入后可能是一堆散落的分组。选中一屏的所有内容 → `Ctrl + Alt + G`（Frame selection）→ 右侧把 `W` 改 `1440`、`H` 改 `900`、`X/Y` 归零。三屏都做一遍，命名 `01 首页` / `02 对练中` / `03 复盘`。

**② 修字体**
全选（`Ctrl + A`）→ 右侧字体那一栏如果显示红色感叹号或 `Inter`，说明字体掉了。换成 **Noto Sans SC**（Figma 自带 Google Fonts，中文没问题）。换完检查一下字重：标题应该是 600，正文 400。

**③ 检查 Auto Layout 有没有活下来**
点侧栏的卡片、消息行、按钮组，右侧面板如果出现 `Auto layout` 那个加号图标，说明这层没有 Auto Layout，按 `Shift + A` 补一个。**至少要保证这几处是 Auto Layout**：侧栏（纵向）、设置卡（纵向）、分段控件那一行（横向）、消息行（横向）、顶栏（横向）。

**④ 颜色改回样式**
导入的颜色大概率是十六进制值，不是样式。全局搜一遍 `#2B55D6`，选中所有用了它的图层，在填充色右边点样式图标 → 选 `accent / 主色`。`#12141A`、`#98A1B0`、`#E6E8EC` 同理。这一步做完，你之前建的 11 个颜色样式才算真的用上。

**⑤ 插件留下的三个常见毛病（10 分钟）**

| 现象 | 怎么处理 |
|---|---|
| **文字被拆成一行一个文本层**（HTML 里换行的地方） | 要改文案的（大标题、空状态正文、气泡）手动重打成一段：选中那几层删掉，`T` 拉一个一样宽的文本框重打。只做 3–5 处；「岗位」「话题数」这种短标签不用管 |
| **阴影丢了，或变成一块硬边灰** | 选中卡片 / 弹层 → 右侧 `Effects` → 换成你建的 `shadow/卡片`；复盘弹层用 `shadow/弹层` |
| **内联图标被转成图片** | 麦克风、附件、时钟最容易。删掉图片，`Shift + I` 搜 `mic` / `paperclip` / `clock` 用 Figma 自带图标，或从 `figma/svg/` 里拷矢量路径 |

### 0.6 然后呢

- **抽组件**（第 4 节）：导入的按钮、气泡都是散图层，把它们 `Ctrl + Alt + K` 变成组件，再补变体。这一步不能省——组件库是「会用 Figma」的硬证据
- **连线**（第 6 节）：原型跳转导入不会带过来，要自己连三条
- **命名**（10 分钟）：插件给的是 `div / .card / Frame 231` 这种名字，面试官会翻图层。只改一层就够：三个屏 frame、侧栏四张卡、四种组件

> 一句话：**A 路线省掉的是「画」，省不掉的是「组件」和「连线」**。这两件恰恰是面试官会问的。

## 0. 路线 B 之前：先定三件事

### 0.1 搭桌面版，不搭手机版

作品集里的 `04-可点击原型.html` 是 **375×812 的手机尺寸**，但真实产品是 **1440 宽的网页**。如果你在 Figma 里照原型搭手机版，面试官会问：「为什么设计稿是手机 App，交付的是网页？」

所以 **Figma 里搭桌面版 1440×900**，配色和尺寸直接照 `web/style.css` 抄，做到「设计稿 = 上线产品」。手机版原型保留在作品集里，定位改成「早期的移动端概念探索」——这在产品叙事上完全成立：先做移动端概念验证，再决定落到桌面 Web。

### 0.2 只搭 3 屏，别贪

| 画板       | 内容           | 为什么是它            |
| -------- | ------------ | ---------------- |
| `01 首页`  | 侧栏设置 + 空状态   | 信息密度最高，能体现布局能力   |
| `02 对练中` | 3 轮对话 + 指标在跳 | 产品的核心价值都在这屏      |
| `03 复盘`  | 弹层报告         | 有分数环、表格、列表，能体现细节 |

**不搭**：登录注册（没有）、往期列表（次要）、错误态（放不进半天）、移动端（见 0.1）。

### 0.3 要证明的四件事

搭的时候心里有数：这份文件不是给用户看的，是给面试官看的。他要看到的是——

1. **Frame + Auto Layout**：改文案时布局不塌
2. **Component + Variants**：一个按钮组件管三种状态
3. **Styles**：颜色和字号是调用的，不是手填的
4. **Prototype**：点「开始对练」真能跳

这四件事齐了，「会用 Figma」就成立了。像素级还原是加分项，不是必需项。

## 1. 建文件与画板（20 分钟）

### 1.1 注册与新建tt

1. 打开 `figma.com`，用 Google 账号或邮箱注册（免费版够用，**免费版有 3 个文件的上限，别乱建**）
2. 首页点 **+ Create new → Design file**
3. 左上角文件名改成 `面试陪练 Agent · UI v1`
4. 按 `Shift + 1` 把视图缩放到全部内容（现在是空的，只是熟悉快捷键）

### 1.2 建三个画板

按 `F`（Frame 工具），在右侧面板的 **Frame 预设列表**里找 `Desktop`，点 **1440 × 900**。

更快的做法：按 `F`，然后在画布上直接拖一个框，松手后在右侧把 `W` 改成 1440、`H` 改成 900。

选中这个画板，在右侧 **Design 面板**改名字：`01 首页`。

然后按 `Ctrl + D` 复制两份，分别改名为 `02 对练中`、`03 复盘`，横向排开（间距留 100px，方便看）。

**命名规矩要立**：画板用 `序号 + 场景`，图层用中文（`侧栏 / 岗位 / 输入框`）。Figma 的图层名会直接出现在交付物里，`Frame 12`、`Rectangle 47` 这种名字一眼就是新手。

### 1.3 打开布局栅格

选中 `01 首页`，右侧面板找到 **Layout grid**，点 `+`：

- 类型选 **Columns**
- 数量 `12`、边距 `24`、间距 `16`
- 颜色用默认的红色半透明，不透明度调到 10%

栅格不是必须的，但打开它有个好处：所有元素会自动吸附到栅格上，间距不会随手写成 13px、17px。

### 1.4 把参考截图垫进来

这是**最省时间的一步**，别跳过。

1. 打开 `http://127.0.0.1:8000/`，按 `F12` → `Ctrl + Shift + M`（设备工具栏）→ 顶部尺寸填 `1440 × 900` → 截图
2. 回到 Figma，按 `Ctrl + Shift + K`（Place image），选刚截的图
3. 拖到 `01 首页` 画板上，尺寸改成 1440 × 900，位置 `X=0, Y=0`
4. 左侧图层面板里把这层改名为 `参考图`，选中它，右侧 **Appearance → Opacity** 调到 `30%`
5. 点图层名右边的小锁，**锁住**（不然一会儿老是误选它）

现在你有了一张半透明的底图，接下来就是「描红」。描完记得删掉或隐藏这层。

> 已有的截图也能用：`eval/shot-home.png`、`eval/shot-chat.png`、`eval/shot-report.png`。但它们是 1440×1080，比例不对，垫进来会差一点，建议还是现截 1440×900 的。

## 2. 先把颜色和字定下来（25 分钟）

**顺序很重要**：先建样式，再画界面。反过来做，你会画到一半发现颜色不统一，然后一个个改。

### 2.1 建颜色样式

在画布空白处点一下（**不要选中任何东西**），右侧面板会出现 **Local styles** 区域，点 `+` 图标 → **Color**。

按这张表建 10 个（数值全部来自 `web/style.css`，一个都别改）：

| 样式名                 | Hex                     | 用在哪          |
| ------------------- | ----------------------- | ------------ |
| `bg / 页面底`          | `#F4F5F7`               | 画板最底层背景      |
| `panel / 面板`        | `#FFFFFF`               | 侧栏、气泡、卡片     |
| `line / 分割线`        | `#E6E8EC`               | 所有 1px 边框    |
| `ink / 主文字`         | `#12141A`               | 标题、气泡正文      |
| `ink2 / 次文字`        | `#5A6473`               | 按钮文字、说明      |
| `ink3 / 弱文字`        | `#98A1B0`               | 标签、占位符       |
| `accent / 主色`       | `#2B55D6`               | 主按钮、选中态、我方气泡 |
| `accent-soft / 主色浅` | `#EEF2FF`               | 选中底色、头像底     |
| `amber / 追问`        | `#A16207` + 底 `#FEF7E0` | 追问标签         |
| `violet / 换题`       | `#6D28D9` + 底 `#F4ECFF` | 换题标签         |

再加两个（复盘页要用）：

|              |                         |      |
| ------------ | ----------------------- | ---- |
| `green / 通过` | `#067A5B` + 底 `#E3F7EF` | 收尾标签 |
| `gray / 澄清`  | `#4B5563` + 底 `#EEF0F3` | 澄清标签 |

**做法**：点 `+` 后弹出面板，`Name` 填名字，`Hex` 填值，点 **Create style**。

### 2.2 建文字样式

同样在 `Local styles` 区，点 `+` → **Text**。按这张表建 8 个：

| 样式名                | 字号   | 行高       | 字重            | 用在哪          |
| ------------------ | ---- | -------- | ------------- | ------------ |
| `h1 / 品牌`          | 16   | 24（150%） | Semi Bold 600 | 「面试陪练」       |
| `h2 / 空状态`         | 22   | 32       | Semi Bold 600 | 「通用岗位，直接开口」  |
| `body / 正文`        | 14.5 | 25（172%） | Regular 400   | 对话气泡         |
| `ui / 控件`          | 12   | 18       | Regular 400   | chip、分段按钮    |
| `ui-strong / 控件选中` | 12   | 18       | Semi Bold 600 | 选中态文字        |
| `btn / 按钮`         | 13.5 | 20       | Semi Bold 600 | 「开始对练」       |
| `label / 标签`       | 11.5 | 16       | Regular 400   | 「岗位」「话题数」    |
| `meta / 小字`        | 11   | 16       | Regular 400   | 底部说明、tagline |

> Figma 的行高可以按百分比填：25 ÷ 14.5 ≈ 172%。

### 2.3 建阴影样式

`Local styles` → `+` → **Effect**，建两个：

| 名             | 值                                                                                       |
| ------------- | --------------------------------------------------------------------------------------- |
| `shadow / 卡片` | `Y=8, Blur=24, Spread=0, rgba(16,24,40,0.06)` + 再加一层 `Y=1, Blur=2, rgba(16,24,40,0.04)` |
| `shadow / 弹层` | `Y=24, Blur=60, Spread=0, rgba(16,24,40,0.22)`                                          |

## 3. 搭第一屏：首页（70 分钟）

### 3.1 先切左右

真实产品是 `304px 侧栏 + 剩余`。在 Figma 里这样做：

1. 选中 `01 首页` 画板，按 `Shift + A` 加 Auto Layout
2. 右侧面板改成：方向 **横向（→）**、`Gap = 0`、Padding 全部 `0`
3. 按 `R` 画一个矩形，宽 `304`、高 `900`，拖进画板里，改填充色为 `panel / 面板`
4. 再画第二个矩形，宽 `1136`（Figma 里把它设成 `Fill container`，宽度会自动填满），填充 `bg / 页面底`
5. 两个矩形分别命名 `侧栏` 和 `主区`，两个都设成 `Vertical` Auto Layout

现在骨架有了。**后面所有内容都往这两个框里塞**，塞进去它们会自动排列。

### 3.2 侧栏：从上到下 5 个区块

侧栏的 Auto Layout 设置：`Vertical`、`Gap = 14`、Padding `20 / 18 / 16 / 18`（上右下左）。

按顺序搭这 5 块：

#### ① 品牌区

- 一个 `38 × 38` 的圆角矩形，圆角 `11`，填充用主色渐变（`#3358D8` → `#1F3BA8`，角度 145°）
- 中间放文字「面」，白色，18px，Semi Bold
- 右边两行文字：「面试陪练」用 `h1 / 品牌`，「会追问 · 会打断 · 会记分」用 `meta / 小字`、颜色 `ink3`
- 整体 `Horizontal` Auto Layout，`Gap = 11`，垂直居中

#### ② 设置卡（最复杂的一块）

- 外层：圆角 `14`、填充 `#FCFCFD`、描边 1px `line`、Padding `14`
- Auto Layout：`Vertical`、`Gap = 14`

里面按顺序放 6 组，每组都是「标签 + 控件」：

**岗位**

- 标签「岗位」用 `label / 标签` + `ink3`，下方 7px
- 一个输入框：宽填满、高 `36`、圆角 `9`、描边 `line`、Padding `8 / 10`，占位文字「写岗位：数据分析师 / 运营」用 `ink3`
- 下面一个 chip「通用岗位」：圆角 `999`、Padding `5 / 12`、描边 `line`、文字 `ui / 控件`
  - 选中态：底 `accent-soft`、描边 `#C5D2F8`、文字 `accent` + `ui-strong`

**话题数**（4 个按钮等分）

- 一个 `Horizontal` Auto Layout，`Gap = 5`，4 个子项都设 `Fill container`
- 每个是圆角 `9`、Padding `7 / 0`、文字居中：`6` `8` `10` `12`
- `8` 是选中态（底 `accent-soft` + 蓝字）

**难度**（3 个等分）

- 同样的做法：`简单` `标准` `困难`，`标准` 选中

**面试方式**（2 个等分）

- `体验式` `正式`，`体验式` 选中
- 下面一行小字（`meta` / `ink3`）：「不带简历，按岗位通用题问，随手练」

**语音**

## 4. 抽组件（45 分钟）

这一步是「会不会 Figma」的分水岭。做完这一节，你的文件就从「一堆图层」变成「一个系统」。

**做法统一**：选中一群元素 → `Ctrl + Alt + K`（Create component）→ 右侧面板出现组件属性 → 点 **Variants** 旁边的 `+` 加状态。

**主组件放哪**：在屏里直接建组件，建完右键 → **Move to page → 组件**。挪到别的页面后实例仍然连着，屏里那几处会自动变成实例——不用「先做组件再替换」，那样反而容易漏。

**开工前先做 60 秒体检**，三项都过了再动手。否则组件会带着错字体和硬编码颜色，三屏套完还要进组件里一个个改：

| 检查 | 通过的样子 | 不通过怎么办 |
|---|---|---|
| 字体 | 选中任意文字，字体栏显示 `Noto Sans SC`（或微软雅黑），无红叹号 | 全选 → 换字体 → 检查标题 600 / 正文 400 |
| Auto Layout | 选中 `div.card`，右侧有 `Auto layout` 区（不是只有一个 `+`） | `Shift + A` 补：侧栏纵向、卡片纵向、分段行横向、消息行横向、顶栏横向 |
| 颜色 | 选中卡片，Fill 显示 `panel` 这类样式名，不是 `#FCFCFD` | 搜色值 → 选中图层 → 填充旁的样式图标 → 套样式 |

### 4.1 按钮 Button（3 个变体）

做成一个组件，属性名 `Type`：

| Type      | 长什么样                           |
| --------- | ------------------------------ |
| `primary` | 填充 `accent`、白字、圆角 10、高 40      |
| `ghost`   | 无填充、无描边、文字 `ink2`、高 36         |
| `mini`    | 白底、描边 `line`、圆角 9、高 33、字号 11.5 |

再给 `primary` 加一个 `State` 属性：`default` / `disabled`（`disabled` 用 `#B9C2D6` 填充）。

### 4.2 分段按钮 Seg（2 个变体）

属性 `State`：`off` / `on`

- `off`：白底、描边 `line`、文字 `ink2`、圆角 9
- `on`：底 `accent-soft`、描边 `#C5D2F8`、文字 `accent`、Semi Bold

**技巧**：变体之间只改颜色，尺寸和 Padding 保持一致，Figma 才能做 Smart animate 过渡。

### 4.3 对话气泡 Message（5 个变体）

这是最重要的一组。属性 `Who` + `Tag`：

| Who     | Tag           | 用在哪       |
| ------- | ------------- | --------- |
| `agent` | `none`        | 面试官普通提问   |
| `agent` | `probe`（追问）   | 琥珀色小标签    |
| `agent` | `clarify`（澄清） | 灰色        |
| `agent` | `switch`（换题）  | 紫色        |
| `me`    | `none`        | 我方回答，蓝底白字 |

结构（`agent` 版）：

- 外层 `Horizontal`、`Gap = 10`、底部间距 20
- 左：`30 × 30` 头像（圆角 9、底 `#EEF1F6`、文字「面」11.5px `#435066`）
- 右：`Vertical` 列，最大宽 `580`
  - 上方 tagline：「第 2 题 · 追问」用 `meta` / `ink3`
  - 气泡：Padding `12 / 15`、圆角 `13`、**左上角单独改成 5**（这是细节，做出来很像真的）
  - `agent` 气泡：白底 + 描边 `line`
  - `me` 气泡：底 `accent`、白字、右上角圆角 5

### 4.4 输入条 Composer（1 个组件就够）

把第 3.3 节做的输入区整体选中，`Ctrl + Alt + K` 变成组件，命名 `Composer / default`。第 5 节复制到 `02` 屏时直接用实例。

### 4.5 顺手做两件事

1. **整理 Assets 面板**：左侧 `Assets` 标签里，新建一个分组叫 `基础组件`，把按钮、分段、气泡拖进去
2. **给组件写描述**：选中组件 → 右侧 `Component` 区 → `Description` 填一句「主按钮，用在开局与复盘弹层」。交付时别人 hover 就能看到

## 9. 时间不够怎么砍

| 你只有 | 做什么 | 砍什么 |
|---|---|---|
| **4 小时** | 全套照做 | 不砍，但第 6.2 节可以跳过 |
| **3 小时** | 01 屏精修 + 02/03 用截图垫底重描关键元素 | 组件库只做按钮和气泡；复盘弹层只做分数环 + 数据表 |

## 10. 面试时怎么说

被问「你在 Figma 里做了什么」，别说「我画了个设计稿」，说这三句：

1. **「我先在 Figma 里把三屏的状态定完，再写代码的。」**——顺序体现流程意识
2. **「颜色和字号我全做成了样式，抽了按钮、分段控件和消息气泡三组组件。气泡有五个变体，追问、澄清、换题各一个标签。」**——这句是硬货，一听就知道真用过
3. **「原型能点通：首页点开始进对练，结束弹复盘，复盘能再练一场。」**——证明不是静态图

被问「为什么设计稿和网页长得一样」，答：「因为这个产品已经上线了，设计稿的定位是交付对齐，不是探索稿。早期的移动端概念稿在作品集的 `04-可点击原型.html` 里，那时候还没决定做桌面还是移动。」
