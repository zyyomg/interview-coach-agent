# 90 分钟收尾 · 照着点

> **起点**：三屏修好了，样式 12 色 + 8 文字已建，组件有「按钮」4 个平级变体 +「气泡」3 个。
> **终点**：封面每一句都是真的，原型点得通，Assets 里 4 组组件，三屏至少一处是实例。

## 0 · 顺序不能反（30 秒）

**组件 → 实例 → 连线 → 封面。**

连线的锚点绑在具体图层上。先连线后换实例，线会断；先换实例后连线，一次成。

全程用左侧图层面板点选，比在画布上拿鼠标戳准得多。

| 步骤 | 干什么 | 分钟 |
|---|---|---|
| 1 | 补 Composer + Seg | 8 |
| 2 | Button 拆成 Type × State | 12 |
| 3 | Message 补到 6 个变体 | 25 |
| 4 | 三屏换上实例（至少 2 处） | 10 |
| 5 | 连线 4 条 | 15 |
| 6 | 封面 + 交付链接 | 5 |

## 1 · 补两组组件（8 分钟）

### 1.1 Composer（3 分钟）

1. 打开 `02 对练中`，框选底部输入区：麦克风方块 + 输入框 + 发送按钮
2. `Ctrl + Alt + K` → 右上角改名 `Composer`
3. 完事。就 1 个，不做变体。

> 主组件留在屏里没关系，Assets 面板是跨页的，别处照样能拖。想整齐再右键 → `Move to page` → 组件页。

### 1.2 Seg（5 分钟）

拿 01 屏现成的「难度」三格改，不用从零画。

1. 图层树里选中「简单 / 标准 / 困难」这一排（三个格子一起）
2. `Ctrl + Alt + K` → 改名 `Seg`
3. `Ctrl + D` 复制一份，把中间格改成选中态：
   - 底 `accent-soft` `#EEF2FF`
   - 描边 `#C5D2F8`
   - 字色 `accent` `#2B55D6`，字重 `Semi Bold`
4. 两份都选中 → 右侧 `Combine as variants`
5. 双击两个变体名，分别改成 `State=off`、`State=on`

> 话题数（4 列）、面试方式（2 列）那两组先不动，它们是不同的组件，面试官不会去数。

## 2 · Button 拆成两个属性（12 分钟）

你现在的 `按钮` 里有 4 个**平级**变体：`primary / secondary / hover / disabled`。Type 和 State 被压成了一个维度。

### 2.1 改名（4 分钟）

双击每个变体名，**按这个格式**写（等号两边没空格，逗号是英文 `,`）：

| 现在 | 改成 |
|---|---|
| `primary` | `Type=primary, State=default` |
| `hover` | `Type=primary, State=hover` |
| `disabled` | `Type=primary, State=disabled` |
| `secondary` | `Type=ghost, State=default` |

回车。Figma 会自动把逗号前面解析成属性名。四行都改完，选中整个变体集，右侧应该出现 **Type** 和 **State 两个下拉**——这就是成了。

### 2.2 补 mini 变体（5 分钟，可跳过）

1. 选中 `Type=ghost` 变体，`Ctrl + D`
2. 改名 `Type=mini, State=default`
3. 右侧改：H `33`、圆角 `9`、padding `0 / 9`、字号 `11.5`、文字改「＋ 文件」
4. 底色白、描边 `line`

### 2.3 改文案（3 分钟）

`ghost` 变体的文字从「开始对练」改成「暂停」——产品里白底描边按钮就用在暂停 / 发送 / 结束 / 下载复盘，不可能写着「开始对练」。

变体集要是排乱了，右键变体集 → `Tidy up`。

## 3 · Message 补到 6 个变体（25 分钟）

### 3.1 先看清结构

真实界面每条 AI 消息都是**两行**：

```
[面]    (追问)                ← tagline：只有一个彩色胶囊，高 18 圆角 99
       ┌──────────────────┐
       │ 这个数含不含未登录的访客？ │   ← 气泡，白底 + 描边 line
       └──────────────────┘      圆角 13，左上角单独改 5，padding 12/15
```

tagline 里**没有题号**。题号在顶部 HUD（`3/8`），气泡上只有一个胶囊。

我方那侧只有气泡，没有 tagline。

### 3.2 给现有 `AI` 变体加 tagline（6 分钟）

1. 双击进入 `AI` 变体，按 `R` 在气泡左上方画一个胶囊：H `18`、W `44`、圆角 `99`、填 `EEF2FF`、无描边
2. 按 `T` 在胶囊里点一下打 `提问`：字号 `10`、色 `2B55D6`；两样一起 `Ctrl + G` 编组
3. 选中这个组 + 气泡 → `Shift + A` → 纵向 Auto Layout，间距 `6`（嫌麻烦就手动摆，不影响交付）
4. 整体贴到头像右边、顶对齐

> 第 3 步如果嫌 Auto Layout 麻烦，就手动摆，变体是固定尺寸，不影响交付。

### 3.3 复制成 5 个标签（12 分钟）

选中加好 tagline 的 `AI` 变体，`Ctrl + D` 四次，每份只改三处：胶囊底、胶囊字色、文字。

| 变体名 | 胶囊底 | 胶囊字色 | 胶囊文字 | 气泡文字 |
|---|---|---|---|---|
| `Who=agent, Tag=提问` | `#EEF2FF` | `#2B55D6` | 提问 | 先说说你在这个项目里具体负责哪一块？ |
| `Who=agent, Tag=追问` | `#FEF7E0` | `#A16207` | 追问 | 这个数含不含未登录的访客？ |
| `Who=agent, Tag=澄清` | `#EEF0F3` | `#4B5563` | 澄清 | 你是想问埋点的口径，还是数据来源？ |
| `Who=agent, Tag=换题` | `#F4ECFF` | `#6D28D9` | 换题 | 好，那换个方向：上线后收到过什么反对意见？ |
| `Who=agent, Tag=收尾` | `#E3F7EF` | `#067A5B` | 收尾 | 今天就到这儿，复盘我整理好了。 |

改名用 **`Ctrl + R`**（整段替换），不要双击（双击会在原名后面追加，Button 那次就是这么坏的）。六份加起来应该是 5 个 `agent` + 1 个 `me`。

### 3.4 收掉两处（7 分钟）

1. 原来的 `用户` 变体 → 改名 `Who=me, Tag=none`；确认它上面**没有** tagline；头像底 `accent-soft`、字 `accent`、文字「你」
2. `正在输入` 直接删掉——产品里没这个东西（真实界面是左下角一个 7px 状态点在闪，气泡里只有一根光标）
3. 全部选中 → `Combine as variants`（如果还是散的）
4. 检查：选中集合，右侧应有 `Who`（agent / me）和 `Tag`（5 个 + none）

## 4 · 三屏换上实例（10 分钟，至少 2 处）

**别用眼睛对位置**，用坐标。

1. 图层面板选中旧的「开始对练」按钮
2. 右侧记下 `X` 和 `Y`（例如 304 / 812）
3. `Delete` 删掉
4. 左侧 `Assets` 面板 → `Button` → 拖 `Type=primary` 到画布
5. 选中新实例，`X`、`Y` 填回刚才那两个数

同样做一遍 01 屏侧栏的「难度」三格 → 换成 `Seg` 实例。

> 只要有一处是真实例，「改主组件三屏跟着变」这套话就立得住。有 10 分钟余量再把 02 屏那三条消息换掉。

## 5 · 连线（15 分钟）

1. 选中 `01 首页` 画板 → 右侧切到 `Prototype` → 勾上 `Flow starting point`（否则演示会从别的画板开始）
2. 选中「开始对练」→ 右侧边缘有个圆形 `+` 把手 → **按住拖到 `02 对练中` 画板的标题上**松手
3. 面板里设：
   - Trigger `On click`
   - Action `Navigate to`
   - Destination `02 对练中`
   - Animation `Smart animate` / `Ease out` / `300 ms`
4. 同样连：`02` 的「结束」→ `03 复盘`
5. 最后一条回路：`03` 的「再练一场」→ `01 首页`，Animation 选 **`Instant`**（重开不该有过渡）
6. 右上 `▶` 演示，点一遍 01 → 02 → 03 → 01

> 拖不上就是目标不对：只能连到 **Frame**（画板）或组件实例上，普通 Group 拖不上去。

## 6 · 封面 + 交付（5 分钟）

封面文案（三行就够）：

```
面试陪练 Agent · UI 设计稿
3 屏主流程 · 4 组组件 · 12 个颜色样式 · 8 个文字样式
怎么读：先看三屏 → 再看组件库 → 右上 ▶ 点通原型
```

- **别再写「6 个文字样式」**，你建了 8 个

- 变体数量封面不用写，写多错多

交付：右上 `Share` → `Anyone with the link` → `Can view` → `Copy link`。

## 附 B · 卡住的时候

| 现象 | 原因 |
|---|---|
| 改完名没出现新属性 | 名字里缺 `=`，或逗号用了中文 `，` |
| 实例位置总差几像素 | 别拖，记下旧图层 X/Y 手填 |
| 连线拖不上去 | 目标不是 Frame；先选画板再拖 |
| 演示从中间开始 | 画板没设 `Flow starting point` |
| 变体排得乱七八糟 | 右键变体集 → `Tidy up` |
| 图标 / 文字掉了字体 | 选中文字，右侧字体框有红叹号就是缺字体，换 `Noto Sans SC` |
